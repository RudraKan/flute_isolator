# Project rules for Claude

- Never co-sign commits: do not add `Co-Authored-By`, `Claude-Session`, or any other attribution
  lines to commit messages or pull request descriptions. Commit messages contain only the change description.
- Keep the GitHub repository private.
- Commit at each working milestone and push regularly.
- Record deferred ideas in `FOLLOWUPS.md` instead of building them.
- Real songs and reference notations live under `data/` (gitignored); never commit them.
